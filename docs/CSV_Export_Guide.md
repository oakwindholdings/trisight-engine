# TriSight CSV Export System - User Guide

## Overview
The TriSight CSV Export System provides comprehensive data export capabilities for ConvictionCloud and TargetReportTable data, enabling seamless integration with Excel and other analytical tools.

## Features

### 🌟 ConvictionCloud Export
- **Conviction Ratings** (0-100 scale)
- **Confidence Levels** (0-1 decimal precision)
- **Traction, Timing, Risk Scores**
- **Pattern Types and Signal Counts**
- **Last Updated timestamps**

### 📊 Target Report Export (Dick's Formula Compliant)
- **Success Score** (Conviction Rating scaled to match Excel formulas)
- **4 Subfactor Scores**: Acceleration, Momentum, Intrinsic Strength, Relative Strength
- **Composite Score** (Automatic average of 4 subfactors)
- **Trigger Details**: Type, Price, Date, Time
- **Excel-compatible formatting**

### 📈 Combined Analysis Export
- **Multi-section CSV** with both ConvictionCloud and TargetReport data
- **Metadata headers** with export timestamps and item counts
- **Comprehensive analysis** for portfolio review

## How to Access

1. **Open TriSight Chart**: Navigate to any chart with active trade signals
2. **Click Export Button**: Look for "📊 Export" in the top-right corner
3. **Choose Export Type**:
   - `☁️ Cloud (#)` - ConvictionCloud data only
   - `📊 Targets (#)` - TargetReportTable data only  
   - `📈 Combined Export` - Both datasets together

## Export Options

### Date Formats
- **US Format**: MM/DD/YYYY HH:MM:SS AM/PM
- **EU Format**: DD/MM/YYYY HH:MM:SS
- **ISO Format**: YYYY-MM-DDTHH:MM:SS.sssZ

### Delimiters
- **Comma (,)**: Standard CSV format
- **Semicolon (;)**: European CSV format
- **Tab**: TSV format for specialized tools

### Additional Options
- **Include Timestamp**: Adds export timestamp to each row
- **Include Metadata**: Adds data source and version information

## File Naming Convention
```
TriSight_[ExportType]_[YYYYMMDD]_[HHMMSS].csv
```

Examples:
- `TriSight_ConvictionCloud_20240629_141523.csv`
- `TriSight_TargetReport_20240629_141523.csv`  
- `TriSight_CombinedAnalysis_20240629_141523.csv`

## Data Validation

The export system includes automatic validation:
- **Required Fields**: Symbol, scores, timestamps
- **Data Types**: Numeric validation for scores, date validation for timestamps  
- **Range Checks**: Scores within expected ranges (0-100, 0-1, etc.)
- **Error Reporting**: Clear error messages for validation failures

## Troubleshooting

### No Data to Export
- **Cause**: No active trade signals or conviction data
- **Solution**: Ensure chart has loaded patterns with active signals

### Export Failed  
- **Cause**: Data validation errors or browser restrictions
- **Solution**: Check browser console (F12) for detailed error messages

### File Not Downloading
- **Cause**: Browser download restrictions
- **Solution**: Check browser download settings and allow downloads from TriSight

## Technical Notes

- **Large Datasets**: Exports are optimized for datasets up to 10,000 rows

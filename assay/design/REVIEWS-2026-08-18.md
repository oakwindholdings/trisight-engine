# Design Reviews — Grammar Extension Mechanism v1 (commit 7639d8d)

Two independent reviews of the v1 design, run before ratification at Bob's insistence — correctly:
the v1 doc was single-author and unreviewed, the exact process gap this project's own Changelog
condemns. Full verdicts preserved here (condensed; full transcripts in session logs). v2 of the
design dispositions every finding by ID.

## Cato (adversarial, cross-vendor; codex GPT-5.4 concurrence on C1/C2/C7) — VERDICT: REJECT as written

Critical: **C1** git_commit is a fixed-point impossibility (a commit SHA cannot live inside the
commit it names) → bind to git tree hash. **C2** cli.ts enforces the epoch chain yet is exempt
from COMPUTE_ROOTS — the laundering vector → verifier code must be inside the hash. **C3** epochs
are self-asserted; nothing re-derives a historical epoch's tree → gate must recompute every
epoch's code_hash from git. **C4** no ordering proof — compute-first-bless-later is undetectable;
genesis epoch is itself retroactive → Results carry epoch_hash resolved at compute time;
after-the-fact blessing permanently flagged; genesis marked retroactive. **C5** review_ref is
theater (non-empty string) → content-addressed, diff-bound Review records, reviewer ≠ declarer.
**C6** no revocation path — bad epochs bless forever → EpochRevocation quarantines dependents.
**C7** kernelCodeHash is non-recursive and .ts-only — family subdirectories escape sealing
entirely → recursive all-file hash + git-ls-files equality assertion.

Major: **M1** Math.pow "discharged" claim is false (engine-dependent, not code-dependent).
**M2** "latest epoch" undefined; forked chains pass → topology assertions (one root, one head,
unique increasing numbers). **M3** repro command as written checks out the store along with the
code → git worktree + explicit --store. **M4** earnings caveat-field is disclosed-but-ignored
reborn; honest path is MEASUREMENT: dual-run on a perturbed calendar, spread as mandatory
adversary slice. **M5** survivorship moves one level down — adjustment vintage, ticker recycling,
vendor coverage floor all unaddressed. **M6** W1 red-first proves one clause; eight attack cases
enumerated. **M7** new guards name no vacuity conditions (file-existence check is vacuous).
**M8** "old seals valid forever" lets published reports become a museum of stale-epoch numbers →
reports gate: stale-epoch receipts force verified:false on the rendered page.

Minor: N1 Epoch not in RecordType/hardcoded scan list; N2 `supersedes` name collision → `parent`;
N3 hourly bars raise session-convention semantics; N4 flag accumulation needs an aggregation rule
(verified requires zero live flags); N5 no declared_by identity; N6 compliance note — the design
honestly stops at the ratification line.

## Forge (peer, GPT-family; codex narrow-slice completed, full pass timed out) — VERDICT: SOUND-WITH-CHANGES

Critical: **F1** = C7 (recursive hash; independently found). **F2** two gate greps (`kernel/*.ts`
globs) also go vacuous for subdirectories. **F3** loadUniverse refuses zero-bar members, so an
honest PIT universe (pre-IPO/post-delisting constituents) refuses every evaluation — kernel needs
date-gated MEMBERSHIP distinct from data availability. **F4** no delisting terminal-value policy —
the sim refuses on the first delisting; must be a declared, hashed Frictions policy with a
sensitivity slice.

High: **F5**=C3, **F6**=C1 (tree hash from git write-tree; anchor commit afterward). **F7** gate
replay hard-fails at the first epoch transition (all 137 traces carry one code_hash), and the
naive patch is vacuous → partition replay by epoch + require a fresh run per epoch. **F8**=C2
(move verification into substrate/; add receipt/ to COMPUTE_ROOTS). **F9**=C5 (plus: review text
must contain the epoch's code_hash so reviews can't be recycled). **F10** grammar_version breaks
all 136 spec hashes; exact fix: optional field, absent-for-v1 via the existing undefined-omission
rule, golden-bytes pin. **F11** vendor-adjusted prices are current-knowledge — AsOf catches
timestamp lookahead, not VALUE-VINTAGE lookahead; declare adjustment_basis/knowledge_basis; acute
for dip-buy price levels. **F12** Frictions.universeAvailability literal maps are a survivorship
back door → rotation family refuses literal maps, requires from_universe_series.

Medium/low: **F13** birth-certificate checks vacuous as specified → six mechanized checks (test
executed with >0 assertions, refusal reasons in the single owner, golden bytes, per-family
ts-expect-error count, injected-unknown-field table test, slicers present in a canonical report).
**F14** Slice.kind closed union blocks family slicers → {family, slicer} keyed to registry.
**F15** per-symbol adversary re-evaluation is quadratic at TS500 scale → land deferred F30 index
+ bounded top-k. **F16** uniform-calendar folds slice rotation cycles mid-cycle → fold schedule
becomes a hashed EvalParams variant; rotation requires cycle_aligned. **F17** interval '1day' is a
hardcoded literal; (interval, periodsPerYear) consistency must refuse. **F18** universe-series
gaps need their own reason + declared cadence. **F19** ticker strings are not identities →
entity_id keying + ambiguous_symbol. **F20** reference/delisted endpoints answer "listed names,"
not "index membership" — sharpen the vendor ask. **F21** vendor delisted coverage has a start
date → coverage_from + refusal below it. **F22** W1 declares TWO epochs atomically (pre-W1 and
W1 trees). **F23** revert case: code_hash alone can't identify an epoch → epoch_hash on every
record. **F24** 107 stored receipts have epoch-blind repro commands → epoch_mismatch refusal with
exact worktree command. **F25**=M1 (+ nothing pins the bun binary; runtime field or land the
deterministic-pow fix). **F26** the same-commit rule isn't mechanizable pre-commit; the
tree-hash-equals-head check subsumes it.

## Convergence

Both reviewers independently demand the same four foundations: epochs bound to **git tree hashes**
and **re-derived from git** by the gate; **verifier code inside the sealed hash**; **recursive
all-file code hashing with a completeness assertion**; and review references that are
**content-addressed and diff-bound**. Both flag the Math.pow discharge claim as false. Where they
differ, Forge supplies the implementation blockers (F3/F4/F7/F10) and Cato supplies the abuse
cases and the measurement design for earnings calendars (M4) — v2 adopts both.

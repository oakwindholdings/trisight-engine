INSTALLATION INSTRUCTIONS:

1. Install Node.js (one-time setup):
   - Double-click the "node-v18.19.1-x64.msi" installer
   - Follow the installation wizard with default options
   - Click "Finish" when complete

2. Run the application:
   - Double-click "run-trisight.bat" to start the application
   - Your default web browser will open automatically
   - The application will load in your browser

3. Using the application:
   - The application will run in your browser but uses data stored locally
   - All chart data and settings are saved between sessions
   - Chart features like zooming, panning, and pattern detection work just like in the web version

4. Closing the application:
   - When you're done using the application, return to the command window
   - Press any key to shut down the application properly
   - Closing your browser without shutting down the application may leave the server running

TROUBLESHOOTING:

If you encounter any issues:
- Make sure Node.js is installed properly
- Try restarting your computer
- If the application won't start, make sure no other applications are using port 3000

For additional support, please contact your TriSight representative.
